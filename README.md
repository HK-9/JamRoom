# JamRoom 🎵

Real-time group listening rooms powered by SoundCloud. Create password-protected rooms, share a queue, chat, and listen together — all in sync.

## Features

- 🏠 **Lobby** — browse live rooms or create your own
- 🔒 **Password protection** — optional per-room passwords (SHA-256 hashed)
- 🎛️ **Member controls** — everyone can play/pause/skip by default
- 👑 **Host authority** — host can lock controls to host-only at any time
- 🔄 **Real-time sync** — every action syncs instantly to all room members
- 🔍 **SoundCloud search** — search and queue tracks from SoundCloud
- 💬 **Room chat** — rate-limited in-room messaging
- 📱 **PWA** — installable on mobile and desktop

## Quick Start

### 1. Install dependencies

```bash
npm install
cd web && npm install && cd ..
```

### 2. Set up environment

```bash
npm run setup dev     # local development
npm run setup prod    # production (Render + Netlify)
```

This writes the correct `.env` files for both the server and frontend automatically.

### 3. Run locally

```bash
npm run dev           # starts both server (port 4000) + frontend (port 5173)
```

Open **http://localhost:5173**

## Deployment

**Frontend** → Netlify ([jamroom-app.netlify.app](https://jamroom-app.netlify.app))
**Backend** → Render ([jamroon-y3c0.onrender.com](https://jamroon-y3c0.onrender.com))

### Deploy workflow

```bash
npm run setup prod    # switch to production env
npm run deploy        # builds frontend + deploys to Netlify
```

Backend deploys automatically when you push to GitHub (Render auto-deploy), or trigger a manual deploy from the Render dashboard.

## API Endpoints

| Endpoint | Description |
|---|---|
| `GET /health` | Server health + room count |
| `GET /api/rooms` | List all active rooms (public) |
| `GET /api/search?q=<query>` | Search SoundCloud tracks |
| `GET /api/resolve/:trackId` | Resolve a SoundCloud track |

## Socket Events

### Client → Server

| Event | Payload | Who |
|---|---|---|
| `room:create` | `{ name, password? }` | Anyone |
| `room:join` | `{ roomId, name, password? }` | Anyone |
| `queue:add` | `{ roomId, track, addedBy }` | Any member |
| `queue:skip` | `{ roomId }` | Host or permitted members |
| `player:update` | `{ roomId, state, positionMs }` | Host or permitted members |
| `room:set-permissions` | `{ roomId, allowMemberControl }` | Host only |
| `chat:send` | `{ roomId, text }` | Any member |

### Server → Client

| Event | Description |
|---|---|
| `room:created` | Room creation confirmation with `roomId` |
| `room:state` | Full room snapshot (users, queue, playback, settings) |
| `room:join:error` | Join failure (wrong password, room not found) |
| `player:sync` | Playback state change from any permitted member |
| `lobby:update` | Updated room list for lobby |
| `chat:new` | New chat message broadcast |
| `error:message` | General error (rate limit, etc.) |

## Environment Variables

| Variable | Used By | Description |
|---|---|---|
| `PORT` | Server | Backend port (default: 4000) |
| `NODE_ENV` | Both | `development` or `production` |
| `VITE_SERVER_URL` | Frontend | Backend URL (blank for dev proxy) |
| `SOUNDCLOUD_CLIENT_ID` | Server | SoundCloud API key |
| `SOUNDCLOUD_CLIENT_SECRET` | Server | SoundCloud API secret |
| `CORS_ORIGIN` | Server | Allowed CORS origins (comma-separated) |

> **Note:** `npm run setup` manages `NODE_ENV` and `VITE_SERVER_URL` automatically. You only need to set `SOUNDCLOUD_*` keys manually.
